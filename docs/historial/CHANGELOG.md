# Registro de cambios de Visbra (reconstruido)

Los registros se basan en paquetes de código preparados para publicación. Las etiquetas a continuación son **planeadas** y quedarán activas cuando se importe el historial Git reconstruido.

## Etapa 1
- `v1.4.0`: primeras herramientas gráficas para aumento de imágenes y BBox.
- `v1.5.0`: notas, recarga de vista previa y configuración de umbrales.
- `v1.6.0`: umbrales por clase en el panel izquierdo.
- `v1.8.0`: guardado automático de umbrales y correcciones de clase.
- `v1.9.0`: persistencia de la última sesión y carpetas.
- `v1.10.0`: entrenamiento y prueba de una CNN de clasificación.

## Etapa 2
- `v2.11.0`: detección multiobjeto y pruebas con monedas.
- `v2.12.0`: separación de entrenamiento/pruebas y umbrales RGB.
- `v2.13.0`: ampliación del aumento de datos (iluminación, color y ruido).
- `v2.14.0`: flujo YOLO, etiquetado multiobjeto y BBox.

## Etapa 3
- `v3.15.0`: perfiles, roles, HMI y herramientas ArUco.
- `v3.15.1`: integración de perfiles y control de vistas.
- `v3.15.2`: organización de menús y controles gráficos.
- `v3.15.3`: mejoras de visualización BBox y panel de prueba.
- `v3.16.0`: cámara en vivo, secuencias y ESP32.
- `v3.16.1`: ajustes de conexión TCP.
- `v3.16.2`: pausa de 3 segundos entre instrucciones.
- `v3.16.3`: saturación visual de la mesa mediante ArUco.
- `v3.16.4`: resultados ampliables, pausa configurable y logotipo actualizado.

**Nota:** la v7 no se incluyó por carecer de un paquete independiente verificado. Los cambios de revisiones puntuales representan entregas identificadas, no fechas originales.
